# Internal engineering docs

Landing zone for the skill suite's tracked artifacts.

- `design/<slug>.md` — written by the `design` skill after user approval. One file per
  feature/change. Template: Problem / Facts found in code / Options considered /
  Decision + why / Task list for implement.
- `impl/<slug>.md` — written by the `implement` skill while executing a spec. Records
  per-task deviations, verification evidence (commands + numbers), and follow-ups.

Throwaway plans (not tracked) go to `.claude/docs/plans/` locally.
